# Urban Wood Furniture — Premium Demo Website

Fictional sales-demo website for a furniture business concept in Coimbatore, Tamil Nadu.

## Run
Open `index.html` directly in a modern browser. No backend or build step is required.

## Files
- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/` (reserved for optional local assets)

## Demo safeguards
- A visible `DEMO WEBSITE` marker is included.
- Statistics and testimonials are explicitly marked as sample/demo content.
- Contact details are fictional placeholders.
- WhatsApp uses a non-operational demo number (`910000000000`).
- Contact form confirms only a demo submission; it does not claim to send data.
- Directions point to generic Coimbatore search results, not a claimed showroom address.
- Structured data is explicitly labeled as fictional demo business data.

## Image licensing
The demo uses remotely hosted Unsplash images for visual presentation. For a client handoff, replace these URLs with the client's licensed/local photography.
